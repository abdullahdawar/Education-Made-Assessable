# Mathematics chapter content blueprint · Grades 1–6

Use this planning template for one grade, subject and chapter at a time. The [Grade 1 roadmap](grade-1-mathematics-curriculum-roadmap.md) supplies the first set of proposed placements. For subsequent grades, obtain the applicable stage framework and verify the exact scope before drafting. Use the same package structure while varying reading length, abstraction, scaffolds and assessment demand by grade.

## Chapter brief

| Field | Record before authoring |
| --- | --- |
| Identity | Grade and Cambridge stage, subject, chapter number, stable chapter reference, English and Pashto titles, revision and review status. |
| Curriculum | Framework edition, page and source link. List each primary objective code and a short paraphrase. Identify objectives used for prerequisite or spiral practice. |
| Learner evidence | For each objective, define a learner-friendly goal, observable success criteria, expected representations and common errors. Specify which evidence needs an adult to observe or listen. |
| Prerequisites and materials | List skills to check and low-cost objects or print equivalents. Give a scaffold for learners who need practice before the core lesson. |
| Delivery | Name the lesson order, estimated effort, activity modes, print plan, accessibility needs, and educator and language reviewers. Use lesson estimates for planning and allow learners to work at their own pace. |

| Illustrated lesson notes | Open with a short “I can” goal and a familiar situation. Use one idea per step, an explicit prompt to try it, and a brief recap. Label mathematical features directly. | Learners can follow the steps using affordable materials. Visual quantities, labels and states agree with the text. | Worked examples | Model a strategy with a concrete object or situation, then show what a learner sees, does and records. Include a contrasting misconception where useful. ### Worksheet and test sequence

| Asset | Purpose |
| --- | --- |
| Worksheet 1 | Guided entry using a familiar representation and a short prerequisite check. |
| Worksheet 2 | Guided practice using a second model or representation. |
| Worksheet 3 | Independent practice of the core objective. |
| Worksheet 4 | Independent variation with changed arrangements, values or contexts. |
| Worksheet 5 | Mixed practice, including an important contrast or common error. |
| Worksheet 6 | Transfer to a practical or less familiar situation. |
| Worksheet 7 | Explain, check or improve a method using words, drawings or objects. |
| Test 1 | Core recognition and execution with limited reading load. |
| Test 2 | Application in a different context or representation. |
| Test 3 | Reasoning, checking or explaining. Include an oral or practical response where it better captures the objective. |

The sequence is a planning default. Set item counts and scoring with the educator. Record a response mode and observation method for actions such as pointing once per object, reading aloud or demonstrating a fair comparison. For multiple objectives, distribute evidence across the three tests and any required observation without adding unnecessary writing.

## Design and delivery gates

1. **Curriculum review.** Approve objective scope, readiness checks, examples, common errors and evidence. Use concrete discovery before abstract recording where appropriate. Plan short achievable steps with feedback that names a useful strategy.
2. **Language review.** Reconcile both language versions item by item. Confirm Standard Written Pashto with a fluent reviewer and verify that English and Pashto learners are asked to do the same mathematics. Test RTL alongside numbers, diagrams, clocks, arrows and any direction-sensitive controls. Manually check assistive-technology pronunciation and focus before release.
3. **Accessibility and bandwidth.** Reuse the visual design system and red panda assets. Use simple illustrations, optimized images, and HTML text and controls where possible. Essential content should load without a video or a large game download. Check English and Pashto at 320, 375 and 1440 px, zoom, keyboard operation, touch, reduced motion, screen-reader feedback and physical mobile layout.
4. **Student and teacher materials.** Keep student notes, tasks and tests in the public package. Student directions should be usable independently or tell learners when to ask a teacher. Keep any teacher-only marking materials under separate access control, outside public source, static assets, API responses and build inputs. Verify the student release contains no worksheets with solutions, downloadable keys or key links.
5. **Publish only reviewed materials.** Confirm the package and placement with the educator and record bilingual and accessibility signoff. Verify resource names, stable links and the actual downloadable files. Test the normal student entry point, language switching and interaction fallback. Any video activation follows its own approval and delivery checks. Use the [Counting release checklist](grade-1-release-readiness.md) as a precedent.

### Existing implementation reference

Chapter 1 already has a bilingual source, Counting Adventure, seven worksheets and three tests per language, and the four student PDFs. Start from the [existing chapter](../curriculum/grade-1-mathematics-counting.md) and its [audit](grade-1-mathematics-curriculum-roadmap.md#chapter-1-audit) when preparing a production brief. Carry forward its existing QA items without duplicating the completed materials. This blueprint describes content and validation requirements and does not require a database schema change.
