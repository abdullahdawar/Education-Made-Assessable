## Authoring and registration

1. Add a bilingual pack under `curriculum/grade-1-maths/` with the chapter number as the filename. The shared validator checks objective placement, language fields, exercise count, safe student-task shape and game solution structure. React loads the matching Grade 1 Mathematics pack lazily. The lesson and PDF tool render from the same text and diagrams. The API retains its existing plain-text translation and student resource routes.
2. Generate four student PDFs per chapter with `python3 curriculum/tools/build-maths-pdfs.py 3 4 ... 13`, substituting the explicit chapter numbers to build. Use `CHROME` to select the Chromium executable when needed. The notes PDF contains a page per lesson. In each practice packet, worksheets are pages 1–7 and tests are pages 8–10. Filenames follow `output/pdf/grade-1-maths-NN-{en,ps}-{notes,worksheets-and-tests}.pdf`. Eleven packs add 44 PDFs and 220 individual student practice resources. The new scope includes no teacher keys or assessment worked solutions.
3. Use the existing [writer setup](../README.md) for authorized databases. Run `python3 curriculum/tools/import-maths-chapters.py --preflight` followed by the explicit chapter numbers for read-only verification and scoped backups. Imports without `--preflight` are transactional per chapter and check existing rows before writing. Plan database rollout separately with owner authorization and a recoverable backup. No writes, credential resets or privilege changes were made on the existing installation.

- A fluent Standard Written Pashto reviewer must approve the new text, language-specific number display, terminology, game instructions, accessible labels and mixed-direction diagram reading. Every new translation is provisional.
- Educators should verify equivalent directions and demand across languages, pacing, handwriting space, and feasible evidence for oral and practical work. Sample shape terminology and the square–rectangle relationship, positional reference frames, measurement tool selection, time conventions, and interpretation of Carroll and Venn diagrams.
